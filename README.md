# verbos
The ultimate conjugation quiz.

The quiz shell is language-agnostic. This pass ships a Spanish content pack: one tap from Play, first round ten typed forms — regular verbs, presente and pretérito — on a 2×5 whose labels come from that pack (yo, tú, él / ella / usted, nosotros, ellos / ellas / ustedes). Customize and What you know wait until a round is finished. Attempts stay on this device.

```bash
npm install
npm test
npm run dev
```
