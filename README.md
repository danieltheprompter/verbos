# verbos
The ultimate conjugation quiz.

The quiz shell is language-agnostic. This pass ships a Spanish content pack: one tap from Play, first round ten typed forms — regular verbs, presente and pretérito — on a 2×5 whose labels come from that pack (yo, tú, él / ella / usted, nosotros, ellos / ellas / ustedes). Customize waits until a Play round is finished. Attempts stay on this device, per person.

School-ready freeze (same lock): on-device profiles, named atlas-fill checks (not locks), Warm-up once a class set is on the device, shareable Customize payload. No loot, XP, streaks, grades-as-score, accounts, or SIS. Customize still opens Subjunctive with zero levels.

```bash
npm install
npm test
npm run dev
```
